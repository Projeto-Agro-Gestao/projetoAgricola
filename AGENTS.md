# Trabalho no AgroGestão

Repositório autorizado: https://github.com/Projeto-Agro-Gestao/projetoAgricola.git.

O checkout integrado é agrogestao-envio dentro do workspace Projeto Agrícola. Confirme git rev-parse --show-toplevel e git status antes de editar. As pastas fluxo-caixa-web e fluxo-caixa-api diretamente na raiz do workspace são cópias antigas fora do Git, não a fonte principal para novas alterações.

O usuário pediu envio das alterações a esse repositório sempre. Faça commit e push das alterações autorizadas e validadas, informando branch e commit confirmado. Preserve alterações alheias e versões mais novas. Branch de integração: feat/agro-integrado-video-20261019. Não efetue merge em main ou publicação de produção sem autorização específica.

Não enviar .env real, credenciais, banco, backups, node_modules, dist ou target. Não alterar preços comerciais, destruir dados ou prejudicar Asaas/autenticação.
